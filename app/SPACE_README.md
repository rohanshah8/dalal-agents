# 🐂 Dalal Agents

**An open-source finance research agent for Indian stocks (NSE/BSE).**

Enter a company name, NSE symbol, or BSE code and select **Analyse**. Explore financial statements,
price trends, ownership, earnings calls, news, and a **competitor edge scorecard** in one report.

Financial metrics, charts, and a template-written narrative work without an API key. Add your own
Anthropic or OpenAI-compatible API key for AI-assisted transcript analysis and report writing.
Download the research as HTML, Markdown, or JSON, including source facts and evidence excerpts.

[Source code and local usage](https://github.com/rohanshah8/dalal-agents) ·
[Example reports](https://github.com/rohanshah8/dalal-agents/tree/main/examples) ·
[Contribute](https://github.com/rohanshah8/dalal-agents/blob/main/CONTRIBUTING.md)

**Outlook & alternatives:** independent 1-week, 1-month and 3-month heuristic scenarios, confidence scores, illustrative price ranges, risks and sources. Alternatives require both higher forecasted return and confidence plus comparable risk, liquidity and fresh data. See [methodology](https://github.com/rohanshah8/dalal-agents/blob/main/docs/OUTLOOK.md). The app also exposes `/api/docs`.

**Not investment advice.** Educational research tool; no buy/sell/hold calls. Forecast scenarios are not price targets or guarantees. Confidence and range coverage are not empirically calibrated.
