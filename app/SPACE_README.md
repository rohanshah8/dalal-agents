# 🐂 Dalal Agents

Open-source AI research analysts for Indian stocks (NSE/BSE): price trends, 12 years of financials,
shareholding, earnings calls, news, and a **competitor edge scorecard**. Every number is cited.

No key needed for the quantitative report. Paste your own Anthropic or OpenAI key for the AI analyst
narrative. It is used only for that run and is never stored.

Source code, methodology and CLI: https://github.com/rohanshah8/dalal-agents

**Not investment advice.** Educational research tool; no buy/sell/hold calls or price targets.
